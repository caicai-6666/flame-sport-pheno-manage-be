TABLE: season_user
ROW_GRAIN: 一行代表一名用户参与一个赛季的记录。
PURPOSE: 连接用户与赛季，并保存正式参与状态、赛季最终积分和积分发放状态。
QUERY_ROLE: 用于查询用户参加哪个赛季、赛季结算积分以及积分是否已发放；不直接表示全局积分余额。
DATA_CHARACTER: 用户与赛季的一对一参与和结算状态。记录存在不等于正式完成报名。
QUERY_INVARIANTS:
- season_user.status 表示已锁定项目数量，不是通用启停状态；不能默认写成 status = 1。
- 正式参与通常需要 season_user.status = season.required_project_count 且 season_user.level_id 非空；只有用户明确要求未完成报名用户时才放宽。
- final_points 为 NULL 表示尚未结算，0 表示已结算但没有积分，正数表示已结算的积分结果。
- points_issued = 0 表示赛季积分尚未写入全局流水，1 表示已经发放；不能用 final_points 非空替代发放状态。
RELATIONSHIPS:
- season: many-to-one。每条记录属于一个赛季。
- user: many-to-one。每条记录属于一个用户。
- point_record: indirect。赛季发放流水通过用户关联，但 point_record 当前没有结构化 season_id。

TABLE: user
ROW_GRAIN: 一行代表一名企业用户。
PURPOSE: 存储用户基础身份、展示资料与部门归属，是用户维度查询的起点。
QUERY_ROLE: 用于定位用户、返回名称和头像、关联部门，以及进入用户的赛季参与数据；用户名称可重名，不能单独视为唯一身份。
DATA_CHARACTER: 平台主数据，不保存登录权限、赛季项目进度、凭证明细或实时积分余额；停用用户的历史参与数据仍保留。
QUERY_INVARIANTS:
- `user.status = 1` 表示当前启用。查询当前可参与用户、当前用户目录或可选用户时默认筛选此条件。
- 历史赛季、凭证、积分或排行榜查询不能因用户已停用而排除其历史数据，除非用户明确要求仅看在职/启用用户。
RELATIONSHIPS:
- department: many-to-one。多个用户可以归属同一个部门；每个用户归属一个部门。
- season_user: one-to-many。一个用户可以参与多个赛季；每条赛季参与记录对应一个用户。

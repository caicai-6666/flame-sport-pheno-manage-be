TABLE: season_user_project
ROW_GRAIN: 一行代表一名赛季用户锁定的一项运动项目。
PURPOSE: 保存用户在该赛季的项目选择及该项目当前完成进度。
QUERY_ROLE: 查询某位用户某个已选项目的当前进度、完成比例或是否已完成时，应以本表为直接来源；项目名称通过 project 取得。逐条凭证、审核过程和按日期历史不由本表回答。
DATA_CHARACTER: 当前项目状态快照。同一赛季参与记录对同一项目最多一条记录；进度始终介于未完成和完成之间。凭证审核会影响此处的当前值，但凭证贡献明细不能替代该当前值。
QUERY_INVARIANTS:
- `season_user_project.status = 1` 表示该项目已锁定且有效；查询用户当前已选项目、项目进度或完成情况时默认必须筛选此条件。
- `status = 0` 表示项目选择无效或已取消，不得计入项目数量、项目进度或完成判定；只有用户明确要求历史取消项目时才可包含。
RELATIONSHIPS:
- season_user: many-to-one。多条赛季用户项目记录可以属于同一条赛季参与记录；每条记录属于一个赛季参与用户。
- project: many-to-one。多条赛季用户项目记录可以对应同一个运动项目；每条记录对应一个项目。
